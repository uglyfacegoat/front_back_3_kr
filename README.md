# BuildPC

Статический сайт на HTML, CSS, Bootstrap 5 и JavaScript. Семь страниц: главная, каталог, конфигуратор, оформление заказа, доставка, контакты и личный кабинет.

- Сайт на GitHub Pages — https://uglyfacegoat.github.io/front_back_3_kr/
- Для локального запуска выполните в этой папке `python3 -m http.server 8080` и откройте http://localhost:8080/.
- Профили, сборки и заявки сохраняются в браузере. Выбор способа оплаты и доставки сохраняется в заявке. Платежи и отправка заказов не подключены.
- Сведения об изображениях и карте находятся в [img/licenses.md](img/licenses.md).
